# Mokausi lietuviškai

Учу литовский — бесплатные тренажёры и материалы для уровня A2 (LT ↔ RU).
Сайт: https://born-to-be-mad.github.io/mokausi-lietuviskai/

**Lietuvos Konstitucija** ([`konstitucija/`](konstitucija/)) — подготовка к экзамену по Конституции Литвы
(для гражданства и постоянного вида на жительство):

| Группа | Что внутри |
|---|---|
| Skaitymas · чтение | лёгкие рассказы с одними героями: «Arbatos vakarai su Konstitucija» — обо всех 14 главах, «Metų šventės» — о праздниках года, «Didieji kunigaikščiai» — о великих князьях; полный текст Конституции по главам; перевод рядом, под строкой или по нажатию, отметки «прочитано» |
| Treniruoklė · тренажёр | термины, глаголы, прилагательные, другие слова, ключевые факты: карточки с интервальным повторением, тест, прогресс по главам; задания — синонимы, лишнее слово, пропуск, окончания |
| Egzaminas · экзамен | пробный экзамен: 20 вопросов, 3 варианта, сдано от 14; в тренировке — перевод по кнопке RU; памятка с числами и сроками на один лист |
| Knygos · книги | книга-пособие PDF: для экрана, для печати (двусторонняя, с QR-кодами на сайт) и чёрно-белая |

- **Озвучка** — записанные литовские голоса на выбор, Ona (женский) и Leonas (мужской), у слов, рассказов и вопросов экзамена.
- **Три вида** — переключатель «Įprasta / Vaikams / Kontrastas» в шапке: спокойное чтение; крупнее и ярче, для детей;
  высокий контраст — крупный чёткий шрифт и толстые рамки. Светлая и тёмная тема во всех трёх.
- Текст Конституции — сводная редакция e-TAR от 22.05.2022 с поправками 2019 и 2022 годов; перевод — неофициальный.

Нашли ошибку — [issues](https://github.com/born-to-be-mad/mokausi-lietuviskai/issues).

Сайт статический (HTML + JS, без сборки); прогресс хранится только в браузере пользователя — его можно сохранить
в файл и загрузить на другом устройстве (без регистрации).
Разделы публикуются из исходных проектов скриптом `deploy_web.sh` — правки данных делаются там, не здесь.
