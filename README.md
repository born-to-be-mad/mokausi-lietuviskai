# Mokausi lietuviškai

Учу литовский — бесплатные тренажёры и материалы для уровня A2 (LT ↔ RU).
Сайт: https://born-to-be-mad.github.io/mokausi-lietuviskai/

**Lietuvos Konstitucija** ([`konstitucija/`](konstitucija/)) — подготовка к экзамену по Конституции:

| Группа | Что внутри |
|---|---|
| Skaitymas · чтение | «Arbatos vakarai su Konstitucija» (`skaitymas.html`) — рассказы с переводом вкл./выкл. и озвучкой |
| Treniruoklė · тренажёр | термины, глаголы, прилагательные, ключевые факты (`index.html?d=…`): карточки, тест, прогресс |
| Egzaminas · экзамен | пробный экзамен (`egzaminas.html`): 20 вопросов, 3 варианта, сдано от 14 |
| Knygos · книги | книга-пособие PDF и версия с QR-кодами для печати |

Сайт статический (HTML + JS, без сборки); прогресс хранится только в браузере пользователя.
Разделы публикуются из исходных проектов скриптом `deploy_web.sh` — правки данных делаются там, не здесь.
